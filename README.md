# Azure Palace

Отдельный mobile-first шаблон свадебного приглашения в небесно-голубой стилистике.

- ID берётся из первого сегмента URL: `/3` → `3`.
- Данные загружаются из Xano через `GET /priglosi/{id}`.
- RSVP сохраняется подтверждённым проектом способом: свежий `GET`, добавление гостя в `guests`, затем `PATCH /priglosi/{id}/full`.
- Поддерживаются `ru`, `ky`, `kk`, динамические блоки, карты и состояния загрузки/ошибки.

```powershell
node scripts/serve.mjs
node scripts/check.mjs
```

Локальная проверка: `http://127.0.0.1:4176/3`.
